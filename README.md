# Roblox Mansion Builder

This project is a Roblox script that automatically builds a mansion with working TVs. The scripts handle the construction of the mansion and the placement of TVs, as well as updating the content displayed on the TVs. The main features include automatic mansion construction, TV placement, and synchronized TV content updates across all players.

## Install

1. Download the project files.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the `MansionBuilder.server.lua` script in the ServerScriptService.
5. Place the `TVController.client.lua` script in the StarterPlayerScripts.

## Use

1. Start the game.
2. The mansion will be automatically built with working TVs.
3. The TV content will be updated with predefined messages.
